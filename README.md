# Shikoportofolio

Build a single-page portfolio website for a graphic designer.

STYLE

- Luxury minimal dark mode: near-black background (#0A0A0A), off-white text, one accent color (warm gold).

- Elegant serif for headlines + clean sans-serif for body. Lots of whitespace.

SECTIONS

Hero (big name + tagline) → Work → About → Services → Contact.

WORK

- Project cards in a responsive grid with filter tabs (All / Branding / Social Media / Packaging / Illustration).

- Filtering animates smoothly. Click a card opens a project detail modal with images + short description.

- Store projects in one easy-to-edit data array.

ANIMATIONS

- Custom cursor that grows on hover over cards and links.

- Parallax on hero and project images.

- Scroll-reveal on every section, staggered card entrance.

- Magnetic buttons, smooth scroll, image zoom on hover, marquee text strip.

OTHER

- Fully responsive, fast on mobile (disable cursor effects on touch).

- Contact: WhatsApp, email, Instagram links. No form.

- Use placeholder content and images.
